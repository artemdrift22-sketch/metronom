# ⏱ Метроном — бесплатная авторассылка в Telegram-чаты

Рассылает твоё рекламное сообщение по выбранным чатам по расписанию — от твоего аккаунта, 24/7.
Компьютер не нужен: всё крутится на твоём личном бесплатном сервере в Render, а настраивается кнопками в боте [@metronom_tg_bot](https://t.me/metronom_tg_bot).

## Как подключить (5 минут)

1. Нажми кнопку — войди в Render через GitHub или Google — **Deploy Blueprint / Apply**:

   [![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/artemdrift22-sketch/metronom)

2. Подожди 2–3 минуты. Открой сервис **metronom** и его ссылку вида `https://metronom-xxxx.onrender.com`.
3. Впиши на странице свои **api_id** и **api_hash** — там же короткая инструкция: [my.telegram.org](https://my.telegram.org) → API development tools → Create application (2 минуты).
   Сайт пишет «ERROR» — включи или выключи VPN, попробуй другой браузер или зайди позже.
4. Войди в Telegram на этой же странице (номер + код или QR-код). Бот сам увидит подключение и пришлёт меню.

Ключи вписываются один раз: сервер хранит их вместе с зашифрованным входом и сам восстанавливает вход после перезапусков.

## Что где хранится

- Вход в Telegram и твои api_id/api_hash — только на твоём сервере.
- Бот хранит адрес сервера, ключ управления и **зашифрованную** копию входа для перезапусков.
  Ключ шифрования (`NODE_SECRET`) создаётся Render при установке и лежит только в настройках твоего сервиса.
- Команд «читать переписку» у сервера нет — смотри `node.py`, код открыт.

## Файлы

| файл | что это |
|---|---|
| `node.py` | сервер клиента: страница входа + рассылка + API для бота |
| `main.py` | ядро рассылки Метронома |
| `page.html` | страница входа (с полями для api_id / api_hash) |
| `render.yaml` | описание сервиса клиента для кнопки Deploy |
| `settings.json` | только имя общего бота (`hub_bot`). Ключей Telegram в репозитории нет |
| `cloud.py` | сервер владельца на Render: запускает бота-пульт и Стража, сам себя будит |
| `tursodb.py` | облачная база Turso для бота-пульта и Стража (стандартный Python, без библиотек) |
| `hub/` | общий бот-пульт |
| `guard/` | 🛡 Страж — бот-модератор пиар-чатов владельца (ОП, кулдаун, капча, продажа рекламы за ⭐) |

Владелец может задать общие ключи переменными окружения `API_ID` и `API_HASH` в Render → Environment сервера клиента — тогда полей на странице не будет.

Обновиться: Render → сервис metronom → **Manual Deploy → Deploy latest commit**. Вход и настройки сохранятся.

## Для владельца

Бот-пульт и Страж ставит мастер установки (`ЗАПУСТИТЬ_УСТАНОВКУ.bat`) — бесплатно, на один сервер Render `metronom-hub`,
базы — в бесплатной Turso (`metronom-hub` и `metronom-guard`). Перезапуски Render базу не стирают.

Свой VPS или Oracle Cloud Always Free — пункт 8 в мастере. Ручная установка Стража на VPS:

```bash
curl -fsSL https://raw.githubusercontent.com/artemdrift22-sketch/metronom/main/guard/install.sh | sudo bash -s artemdrift22-sketch/metronom
```

Потом в Telegram: `/login` → пароль → 💬 Чаты → ➕ Добавить чат. Только стандартный Python 3.9+, без зависимостей.
